# 算力适配门户协议

页面 / 提供卡型、驱动、框架、精度四个可见控件；切卡重建驱动与框架，页面提示“结果更新中”后才展示当前结果。状态“不支持”“尚未测”“通过”是发布方给出的不同事实。详情 /detail 由可见链接进入，含组合标识、修订、实际驱动构建、算子子项和下载链接；同名 test-result.bin 依组合及修订区分，字节是合成测试记录。
采集业务只操作用户可见控件、详情和下载，不把浏览器内部请求 /ui/* 当成受支持采集API，不读取JS对象。源码对本地演练开放便于检查来源，不能绕开页面边界。
本地控制 correct 可指定card=c1/c2，只增加该卡修订并把部分算子改为失败，汇总仍显示通过以提供可观察矛盾；framework增加next分支，状态为尚未测。别名d10、d9对应实际构建10.12.3+build7、9.10.9+build12，不能按小数排序。

本地来源控制通过 POST /__control 发送JSON，例如 {"event":"reset"} 可重置样本。控制切换只影响合成来源，不能用来替业务处理方决定批准、签发或确认。来源服务与自动化客户端分别承担各自责任。
